# MARGO Flutter

Нативный клиент для Windows, Android и Linux. Общая инструкция находится в ../../README.md.

- lib/app — тема, маршруты и адаптивная оболочка;
- lib/features — онбординг, статья дня, библиотека, статистика и профиль;
- lib/data — Dio, SQLite и защищённое хранение токена;
- lib/sync — Riverpod-контроллер и очередь операций;
- lib/notifications — локальные напоминания;
- test — восстановление очереди, потерянный ответ сервера, компоновка экранов.

Никакого локального ранжирования: рекомендацию назначает FastAPI, клиент только кэширует серверные данные.
