# Android APK

## Сборка

```powershell
$env:MARGO_ANDROID_CERT_SHA256 = '47cdf9c65e2bd828b455430785c983ba6e50a804c8c06bd6f8c21e06900a52ad'
./scripts/build-android.ps1 -AllowLegacyDebugCertificate -PreviousApk .secrets/margo-signing/previous-0.4.3-11.apk
```

Результат release-сборки: `dist/MARGO-Android.apk`. Это универсальный APK для ARM64, ARMv7 и x86_64. Минимальная версия — Android 7.0 (API 24), обусловлена текущими версиями платформенных плагинов.

Для отладки:

```powershell
./scripts/build-android.ps1 -Mode debug
```

Скрипт использует локальные Flutter (`.tools/flutter`), Temurin JDK 21 (`.tools/java`), Android SDK (`.tools/android-sdk`) и Gradle cache (`.tools/gradle`), если они подготовлены на этом компьютере. Они не входят в APK и не нужны на телефоне. На другом компьютере инструменты разработки нужно установить отдельно и принять лицензию Android SDK.

Gradle использует NDK версии `flutter.ndkVersion` из общей папки Android SDK; она должна быть доступна приложению и нативным плагинам.

## Подключение к серверу

Для просмотра прототипа сервер не нужен: на первом экране нажмите **«Попробовать без аккаунта»**. Четыре демонстрационные карточки встроены в APK. Избранное, оценки, отметки прочтения и настройки сохраняются локально и доступны после перезапуска. В профиле можно выйти из деморежима или сбросить его данные. Демоданные не отправляются на сервер при последующем входе. Карточка-пример фиксирована, новые персональные статьи и уведомления без сервера не назначаются. Оригинал Википедии открывается в браузере и требует интернета.

Адрес сервера задаётся при сборке параметром API_BASE_URL. Создание аккаунта и новые рекомендации требуют интернета. Загруженные карточки, оценки и избранное доступны офлайн с последующей синхронизацией. Для работы с локальным API в Android Emulator запустите `flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000`.

## Установка и подпись

Передайте APK на телефон и откройте его, затем подтвердите установку в системном установщике Android. Включение разрешения установки из выбранного источника пользователь выполняет самостоятельно, если ОС его запрашивает.

Release APK требует отдельной явно настроенной конфигурации подписи; fallback на debug удалён. Для обновления существующих установок сохранён прежний закрытый ключ в защищённом паролем release keystore. Исторический debug-сертификат разрешается только явным флагом вместе с закреплённым отпечатком. Это канал прямой установки, не публикация в Google Play. Хранение, восстановление и проверка совместимости описаны в [release-signing.md](release-signing.md).

После сборки подпись проверяется `apksigner verify --verbose`, структура и минимальная версия Android — `aapt dump badging`. Проверка APK не заменяет запуск на физическом устройстве.

Иконка локальных уведомлений `ic_notification` загружается плагином по имени. Правило в `apps/margo_flutter/android/app/src/main/res/raw/keep.xml` сохраняет её при оптимизации release-сборки. После изменения ресурсов проверьте, что `aapt dump resources dist/MARGO-Android.apk` содержит `drawable/ic_notification`: без неё инициализация уведомлений завершается ошибкой `invalid_icon`.
