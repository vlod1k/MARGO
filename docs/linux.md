# MARGO для Linux

Скачайте `MARGO-<версия>-x86_64.flatpak` со страницы [выпусков MARGO](https://github.com/vlod1k/MARGO/releases). Для установки нужны Flatpak, графическая сессия и доступ к Flathub для загрузки среды GNOME 49. При запуске MARGO проверяет сохранённую сессию. Для этой проверки нужен доступ к системному Secret Service, например GNOME Keyring или совместимому KDE Wallet.

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user --bundle '/путь/к/MARGO-<версия>-x86_64.flatpak'
flatpak run io.github.vlod1k.MARGO
```

После установки MARGO появится в меню приложений. Используйте аккаунт от Windows или Android, чтобы синхронизировать библиотеку. Офлайн доступны загруженные карточки и сохранение действий до следующей синхронизации. Доставка ежедневных напоминаний в Linux пока недоступна.

Для обновления скачайте новый `.flatpak`, закройте MARGO и установите файл поверх предыдущего той же командой. Пакет хранит данные в каталоге `~/.var/app/io.github.vlod1k.MARGO`. Самостоятельный канал автоматических обновлений требует отдельного Flatpak-репозитория.

## Сборка

На машине x86_64 установите Flatpak и flatpak-builder, затем выполните из корня репозитория:

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub org.gnome.Sdk//49 org.gnome.Platform//49 org.freedesktop.Sdk.Extension.llvm21//25.08
./scripts/build-linux-flatpak.sh
```

Скрипт запускает анализ и тесты Flutter в GNOME SDK, собирает выпуск и сохраняет `.flatpak` в `dist/`. Для первой сборки нужен интернет для загрузки Flutter, зависимостей Dart и среды GNOME. Версия Flutter и контрольная сумма архива закреплены в манифесте. Пакет использует тот же API по умолчанию, что и Windows и Android.

Workflow **MARGO Linux Flatpak** сохраняет проверенный пакет как артефакт CI. При публикации GitHub Release workflow собирает его из тега выпуска и прикрепляет к релизу после проверки установки и входа в деморежим.

## Приёмка на CachyOS

- Установите пакет и запустите MARGO из меню приложений. Проверьте иконку и запуск через `flatpak run io.github.vlod1k.MARGO`.
- Откройте деморежим, добавьте статью в избранное и проверьте сохранение после перезапуска.
- Войдите в тестовый аккаунт с разблокированной системной связкой ключей. После перезапуска должен открыться тот же профиль.
- Отключите сеть, измените состояние избранного или отметку прочтения. Включите сеть и проверьте, что действие отправилось и появилось на втором устройстве.
- Откройте полный текст статьи в системном браузере. Проверьте, что новый пакет устанавливается поверх старого и сохраняет локальные данные.
